# Installation

## Stable release

To install DI_proj_germany, run this command in your terminal:

```sh
uv add DI_proj_germany
```

Or if you prefer to use `pip`:

```sh
pip install DI_proj_germany
```

## From source

The source files for DI_proj_germany can be downloaded from the [Github repo](https://github.com/APVsiris/DI_proj_germany).

You can either clone the public repository:

```sh
git clone git://github.com/APVsiris/DI_proj_germany
```

Or download the [tarball](https://github.com/APVsiris/DI_proj_germany/tarball/master):

```sh
curl -OJL https://github.com/APVsiris/DI_proj_germany/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd DI_proj_germany
uv pip install .
```
